# 背景音乐投放说明

把婚礼背景音乐放成 **`wedding.mp3`**，放在本目录下：

```
public/music/wedding.mp3
```

## 为什么要放这里，而不是 import 进代码

- 音频体积大，进 git 会让仓库迅速膨胀、每次 clone 都很慢
- 放 `public/` 由构建原样拷贝，构建产物路径固定为 `/wedding/music/wedding.mp3`
- 换音乐不用改代码、不用重新构建，只替换文件即可

## 素材要求

| 项目 | 建议 | 原因 |
|---|---|---|
| 格式 | **mp3**（兼容性最稳，微信内置浏览器实测最稳） | m4a/aac 在部分安卓微信上解码异常 |
| 大小 | **≤ 3 MB** | 走流量加载，太大会让宾客等很久 |
| 时长 | 2–4 分钟 | 长了文件大，短了循环时能听出接缝 |
| 风格 | 轻音乐 / 钢琴 / 弦乐，不要有人声 | 有歌词会和页面文案打架，且容易喧宾夺主 |

## 压缩建议

ffmpeg 转成 128k 单声道，体积能降到 1/4：

```bash
ffmpeg -i 原曲.m4a -vn -ac 1 -b:a 128k -ar 44100 public/music/wedding.mp3
```

## 没放文件会怎样

组件会检测音频文件是否可加载，**加载不到就不渲染播放按钮**，页面不会出现
一个点了没声音的摆设。不会报错、不会打扰宾客。

放完文件后 push 一次即可生效（CI 会自动重新部署），**不需要改任何代码**。

## 循环接缝

音乐默认循环播放。挑曲子时留意结尾能不能自然接回开头，
接缝明显的曲子宾客听几遍会觉得卡。必要时可以在音频编辑器里做个循环裁切。
